# 其他电脑访问知识库 + 上传/删除自测（傻瓜步骤）

下面假设**跑知识库后端**的那台电脑 IP 是 **`<YOUR_SERVER_IP>`**（请改成你真实的 IP）。后端端口默认 **`3001`**。

---

## 零、两台电脑都要满足

1. **知识库后端已启动**（那台机上 `npm run dev` 或单独起 backend，能听到 `3001`）。
2. **Windows 防火墙**（或安全软件）允许 **入站 TCP 3001**（否则别的电脑连不上）。
3. 另一台电脑和它在**同一内网**（能互相 ping 不一定够，但要能访问 `http://IP:3001`）。

---

## 〇、对接 OpenClaw / 其它系统：检索 + 上传 + 删除（统一用 `X-API-Key`）

下面三件事都用同一个约定，**不用先登录**：

| 项目 | 说明 |
|------|------|
| **API 根** | `http://<服务器IP>:3001/api/v1`（下面用 `<YOUR_SERVER_IP>` 举例，请改成你的 IP） |
| **每个请求都加请求头** | `X-API-Key: sk-bge-m3`（改成你在 **`backend/.env`** 里 **`API_KEYS`** 配的那把密钥） |

**`.env` 里密钥怎么写：** 见文末「密钥配置」；上传时 **`visibleDeptIds`** 要与密钥能访问的部门一致（一般用 `101` 或你们库里的部门 ID）。

---

### 〇-1 检索（POST，JSON）

- **地址：** `POST http://<YOUR_SERVER_IP>:3001/api/v1/search`
- **头：** `Content-Type: application/json`，`X-API-Key: sk-bge-m3`
- **请求体（JSON）：**

**只要网页那种「大模型总结回答」（推荐）：** 需配置可用的 **`VLLM_*`**，并这样写：

```json
{
  "query": "你要查的问题",
  "topK": 8,
  "includeAnswer": true,
  "includeHits": false
}
```

- 答复正文在返回的 **`data.rag.answer`**；引用在 **`data.rag.citations`**（若有）。
- **`includeHits`: `false`** 表示响应里**不再带**那一长串检索片段（服务端仍会检索后交给大模型）。

**只要检索片段、不要大模型（更快）：**

```json
{
  "query": "你要查的问题",
  "topK": 8,
  "includeAnswer": false
}
```

此时返回里主要是 **`data.hits`**（每条里的 `text_preview` / `content` 等即片段）。

**PowerShell 示例（仅要 RAG 答复）：**

```powershell
$base = "http://<YOUR_SERVER_IP>:3001"
$key = "sk-bge-m3"
$h = @{ "Content-Type" = "application/json"; "X-API-Key" = $key }
$b = '{"query":"请假怎么申请","topK":8,"includeAnswer":true,"includeHits":false}'
Invoke-RestMethod -Uri "$base/api/v1/search" -Method Post -Headers $h -Body $b
```

---

### 〇-2 上传文件入库（POST，multipart）

**和「检索」对照（一眼看懂）：**

| | **检索** `POST .../search` | **上传入库** `POST .../documents/upload` |
|--|---------------------------|-------------------------------------------|
| Body 类型 | **JSON**（raw） | **form-data**（表单），**不是 JSON** |
| 你在 Apifox 里 | 贴 `{"query":"...","includeAnswer":true,...}` | 一行一行加字段：`files` 选文件、`visibleDeptIds` 填 `[101]` |
| 文件 | 无 | **必须有** `files` 这一行（类型选「文件」） |

**没有「一个 JSON 结构体」**：上传走的是 **`multipart/form-data`**（表单），**文件 + 若干文本字段**。Apifox 里选 **Body → form-data**，不要选 JSON。

- **地址：** `POST http://<YOUR_SERVER_IP>:3001/api/v1/documents/upload`
- **头：** `X-API-Key: sk-bge-m3`  
  - Apifox：**不要**手写 `Content-Type`；选 form-data 后工具会自动带 `multipart/form-data; boundary=...`。

**表单字段一览（与后端 `documents/upload` 一致）：**

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| **`files`** | **文件** | **必填** | 字段名必须是 **`files`**；可多行多个文件（每个都是 `files`，或工具支持「同一字段多文件」）。单文件 ≤25MB。 |
| **`visibleDeptIds`** | 文本 | **API Key / 非管理员必填** | 可见部门 ID 列表：**JSON 数组字符串** ` [101]` 或 **`101,102`**。与 `API_KEYS` 里配置的部门范围一致。 |
| **`deptScopeCompanyWide`** | 文本 | 否 | 仅 **`admin`** 账号有效：填 **`1`** 或 **`true`** 表示全公司可见；API Key 角色一般为 **service**，**不要依赖此项**，请带 **`visibleDeptIds`**。 |
| **`deptScopeIncludeChildren`** | 文本 | 否 | **`1`** / **`true`**：可见部门含下级。 |
| **`knowledgeType`** | 文本 | 否 | **`FAQ`** / **`制度`** / **`方案`** / **`文档`**，或留空。 |
| **`author`** | 文本 | 否 | 作者，最长约 256 字。 |
| **`docVersion`** 或 **`version`** | 文本 | 否 | 版本号。 |
| **`sourceUri`** 或 **`source`** | 文本 | 否 | 来源 URI。 |
| **`departmentCaption`** 或 **`department`** | 文本 | 否 | 部门展示名。 |
| **`categoryDeptIds`** | 文本 | 否 | 类属部门，JSON 数组或逗号分隔；与网页「类属」一致。 |
| **`categorySameAsVisible`** | 文本 | 否 | **`0`** / **`false`** 时需配 **`categoryDeptIds`**；默认与可见部门一致。 |

**Apifox 最小可跑示例：** 新增两行 form-data —— **`files`** 选类型「文件」并选本地文件；**`visibleDeptIds`** 类型「文本」，值填 **`[101]`**（按你们部门改）。Header 里加 **`x-api-key`**。

**PowerShell + curl 示例：**

```powershell
$base = "http://<YOUR_SERVER_IP>:3001"
$key = "sk-bge-m3"
curl.exe -X POST "$base/api/v1/documents/upload" -H "X-API-Key: $key" -F "files=@C:\Users\你的用户名\Desktop\kb-test.txt" -F "visibleDeptIds=[101]"
```

成功返回里会有 **`batchId`**，入库是异步的，过几秒再在文档列表里能看到。

### 〇-3 查文档列表、拿 `id`（GET）

删除前要文档 **UUID**（`id` 字段）：

- **地址：** `GET http://<YOUR_SERVER_IP>:3001/api/v1/documents?page=1&pageSize=20`
- **头：** `X-API-Key: sk-bge-m3`

**PowerShell：**

```powershell
Invoke-RestMethod -Uri "$base/api/v1/documents?page=1&pageSize=20" -Headers @{ "X-API-Key" = $key }
```

在返回的 **`data.items`** 里找到对应文件的 **`id`**。

---

### 〇-4 删除文档（DELETE）

- **地址：** `DELETE http://<YOUR_SERVER_IP>:3001/api/v1/documents/{文档UUID}`
- **头：** `X-API-Key: sk-bge-m3`
- **无请求体**

**PowerShell：**

```powershell
$docId = "把上一步抄到的UUID贴在这里"
Invoke-RestMethod -Uri "$base/api/v1/documents/$docId" -Method Delete -Headers @{ "X-API-Key" = $key }
```

---

### 密钥配置（`backend/.env`）

- **推荐：** `API_KEYS=你的密钥=101,102`（`=` 后是 API Key 对应的可见部门 ID）
- **只写密钥：** `API_KEYS=sk-bge-m3`（未写 `=` 时，会用 **`API_KEY_DEFAULT_DEPT_IDS`** 或 **`DEV_USER_DEPT_IDS`**，都没有则默认 **`101`**）

改完 **`.env` 要重启后端**。

更多路径说明：`GET http://<IP>:3001/api/v1/openapi.json`。

下面 **「二、登录拿 Token」** 是给**人工网页式**用的；**OpenClaw / 脚本优先用本节 〇**。

---

## 一、在「别的电脑」上确认能连上

用浏览器打开：

```text
http://<YOUR_SERVER_IP>:3001/api/v1/ready
```

若看到 JSON 里类似 `"sql":true,"qdrant":true`（或整体 `code:200`），说明**网络和后端**通了。

---

## 二、登录拿 Token（像拿一把临时钥匙）

打开 **PowerShell**（密码按你服务器 `backend/.env` 里 `DEV_PASSWORD`，默认常为 `123`）。

**推荐方式 A — `Invoke-RestMethod`（在 Windows 上最稳，你已验证可用）：**

```powershell
$base = "http://<YOUR_SERVER_IP>:3001"
$body = @{ loginId = "admin"; password = "<YOUR_PASSWORD>" } | ConvertTo-Json
$r = Invoke-RestMethod -Uri "$base/api/v1/auth/login" -Method Post -ContentType "application/json; charset=utf-8" -Body $body
$token = $r.data.token
$token
```

后面凡是要带登录态的请求，都可以用：

```powershell
$h = @{ Authorization = "Bearer $token" }
Invoke-RestMethod -Uri "$base/api/v1/documents?page=1&pageSize=5" -Headers $h
```

**方式 B — curl（PowerShell 里请用变量传给 `-d`，不要直接内联 `'-d '{...}'`，否则容易出现空 body → 服务器 500）：**

```powershell
$base = "http://<YOUR_SERVER_IP>:3001"
$json = '{"loginId":"admin","password":"<YOUR_PASSWORD>"}'
curl.exe -s -X POST "$base/api/v1/auth/login" -H "Content-Type: application/json" --data-binary $json
```

> 若登录账号不是 admin，把 `loginId`/`password` 改成你们真实的。

**若 Invoke-RestMethod 仍失败**：到**跑后端的那台电脑**上看 Node 终端报错；常见有 SQL Server / `sqlcmd` 问题。

---

## 三、上传一个测试文件（入库）

先在本机随便建一个小文件，例如桌面上的 `kb-test.txt`，里面写几个字。

在**同一台「别的电脑」**上执行（**两处**改成你的：IP、`你的TOKEN`、以及文件路径）：

```powershell
curl.exe -X POST "http://<YOUR_SERVER_IP>:3001/api/v1/documents/upload" -H "Authorization: Bearer 你的TOKEN" -F "files=@C:\Users\你的用户名\Desktop\kb-test.txt" -F "deptScopeCompanyWide=1"
```

说明：

- **`deptScopeCompanyWide=1`**：表示「全公司可见」，只有 **admin** 账号这样传才合法；和开发环境默认 admin 一致。
- 若不是 admin，要改成传可见部门，例如：`-F "visibleDeptIds=[101]"`（数字按你们部门来）。

成功时返回 JSON 里会有 **`batchId`**，表示已排队入库（过几秒到几十秒不等，取决于 Embedding/Qdrant）。

## 四、看知识库里有没有这条文档

**PowerShell（推荐）：**

```powershell
Invoke-RestMethod -Uri "$base/api/v1/documents?page=1&pageSize=20" -Headers @{ Authorization = "Bearer $token" }
```

**或 curl：**

```powershell
curl.exe -s "http://<YOUR_SERVER_IP>:3001/api/v1/documents?page=1&pageSize=20" -H "Authorization: Bearer 你的TOKEN"
```

在返回的 **`items`** 里找标题 **`kb-test.txt`**（或你上传的文件名）。记下该项的 **`id`**（一长串 UUID），下面删除要用。

也可以：在跑服务的那台机浏览器打开前端 **`http://<YOUR_SERVER_IP>:5173`**（若 dev 已开），登录后在「文档库」里看是否出现。

---

## 五、删除这条文档（看知识库有没有变）

把 **`文档UUID`** 换成上一步抄的 **`id`**。

**PowerShell：**

```powershell
Invoke-RestMethod -Uri "$base/api/v1/documents/文档UUID" -Method Delete -Headers @{ Authorization = "Bearer $token" }
```

**curl：**

```powershell
curl.exe -s -X DELETE "http://<YOUR_SERVER_IP>:3001/api/v1/documents/文档UUID" -H "Authorization: Bearer 你的TOKEN"
```

成功会返回 **`code":200`** 一类提示。

## 六、再查一次列表，确认变化

```powershell
Invoke-RestMethod -Uri "$base/api/v1/documents?page=1&pageSize=20" -Headers @{ Authorization = "Bearer $token" }
```

**预期**：刚才那条 **`kb-test.txt`** 不再出现在列表里（或状态不再是正常可检索；实现上是软删，列表接口通常不再当正常文档展示）。

## 七、更省事的做法（不想用命令行）

在「别的电脑」浏览器直接打开（后端那台 IP 要通）：

```text
http://<YOUR_SERVER_IP>:5173
```

用 **admin / 123**（或你们账号）登录 → **文档库**里上传文件 → 看列表 → 再点删除。效果和上面 curl 自测一致，只是不用复制 Token。

## 常见问题

| 现象 | 怎么办 |
|------|--------|
| 连接超时 | 检查 IP、后端是否启动、防火墙是否放行 **3001** |
| 401 未登录 | Token 过期了，重新做「二、登录」 |
| **curl 登录 500，但 Invoke-RestMethod 正常** | 换「二、方式 A」或 curl 用 **`$json` 变量 + `--data-binary`**，勿在 PowerShell 里内联 `-d '{...}'` |
| 上传提示要 visibleDeptIds | 不用全公司时，加上 `-F "visibleDeptIds=[101]"` 或换 admin + `deptScopeCompanyWide=1` |
| 列表里暂时没有新文件 | 等几秒再刷新；看后端入库任务是否报错（Embedding/Qdrant 要正常） |

更全的接口列表见：`GET http://<YOUR_SERVER_IP>:3001/api/v1/openapi.json`。
